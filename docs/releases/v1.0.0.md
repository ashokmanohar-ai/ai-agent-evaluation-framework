# v1.0.0 — AI Agent Evaluation Framework

This first stable portfolio release provides a deterministic-first framework for measuring whether AI agents complete tasks correctly, use tools safely and preserve evidence across their execution trajectory.

## Included evidence

- provider-independent AgentAdapter and normalized AgentTrace contracts
- 70 versioned cases across task, tool, trajectory, grounding, recovery and safety
- approval and high-impact tool policy with zero-tolerance safety drift
- structured optional LLM judge with schema, timeout and prompt-version controls
- baselines, regression limits, repeated runs and transparent weighted scoring
- console, JSON, accessible HTML, JUnit, FastAPI, Docker and telemetry outputs
- a recruiter quick tour and five-minute credential-free proof path

## Scope and limitations

All included cases and domain functions are synthetic. The mock provider makes CI reproducible; production-model evaluation still requires organization-specific datasets, thresholds and risk approval.
